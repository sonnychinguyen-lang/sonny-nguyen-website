# Sonny Nguyen — portfolio

React + react-three-fiber site built on the pmndrs "raycast-cycling" (A flight of stairs) example, with a ShaderGradient background, MapLibre GL JS + deck.gl maps, r3f-forcegraph networks, and recharts.

## Run it
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build -> dist/

Deploy `dist/` to Netlify (drag-and-drop or connect the repo). `public/_redirects` makes the routes work; the contact form uses Netlify Forms and activates automatically on deploy.

## Personal section and portals
- `/personal` — photography (the image-gallery example; photos in `public/photos/`, captions in `src/data/photos.js`) and the macro-counter shell.
- The E-HOLDUP timeline is the enter-portals example. Backdrops live in `public/portals/<event-id>.jpg` (illustrated placeholders generated by `scenes.py`); replace any of them with your own ComfyUI renders — same filename, nothing else changes.

## Deploying via GitHub Pages (instead of Netlify)
This repo includes `.github/workflows/deploy.yml`. Once pushed to GitHub:
1. Repo Settings → Pages → Source: set to **GitHub Actions**.
2. Push to `main` (or run the workflow manually from the Actions tab).
3. The site publishes at `https://<username>.github.io/<repo-name>/`.

Two things are wired specifically for this:
- `vite.config.js`'s `base` and the router's `basename` are set to `/sonny-nguyen-website/` to match this repo's name. **If you rename the repo, update both** (search for `sonny-nguyen-website`).
- `public/404.html` + a small script in `index.html` implement the standard "SPA on GitHub Pages" redirect trick, since GitHub Pages can't rewrite deep links like `/resume` the way Netlify's `_redirects` does.

If you switch back to Netlify later, none of this needs removing — Netlify ignores the extra 404.html trick and `_redirects` still exists for it as well; you'd just want to set `base: '/'` again in vite.config.js and `basename=""` in App.jsx for a cleaner root-domain URL.

## Data
Everything under `public/data/` is generated from the coursework files by `pipeline.py` (kept in the repo root): UTM→WGS84 reprojection, the kernel-density grid, the Green Timbers buffer selection, the four explorer layers with burglary MO joined by file number, the Toronto MCI time series, and the compact dashboard rows. Re-run it with the source spreadsheets in `/uploads` to regenerate.

## Tour
The stairs order is also a 14-step tour. On any project page the glass control at bottom-right (or the ← → keys) moves to the previous/next step; the front page has a "Start the tour" button. Each move plays a short shader wipe (`src/components/Transition.jsx`, plain GLSL on a react-three-fiber plane). Order and labels come from `src/data.js` → `stairs`.

## Pages
- `/` — the stairs. 12 slabs = 12 documents across 4 projects. Hover previews, click opens, scroll/Tab cycles stacked slabs.
- `/resume` — generalized resume + contact form. Content in `src/data/resume.js`; the PDF in `public/files/` is generated from the same file (`scripts` note below).
- `/projects/eholdup` — 3D map of the robbery series (deck.gl over MapLibre), the people chart (3d-force-graph with 3D figures; click a figure for its profile and timeline), phone network with full numbers, the timeline as a reflective 3D gallery, report.
- `/projects/surrey-density` — density as extruded columns vs. 3D buildings + terrain, with a toggle; Jan–Apr / May–Aug / net change tabs.
- `/projects/green-timbers` — 800 m buffer map with offences by type.
- `/projects/moss-park` — demographics, CompStat thresholds (+ 3D columns over the neighbourhood), 11-year MCI series, day-of-week and hour by crime type (from raw rows).
- `/projects/caper` — offence explorer: burglary / street robbery / auto theft / prostitution layers over Surrey, points or hex density, hour and weekday profiles, burglary MO breakdown.
- `/projects/dashboard` — Surrey B&E dashboard: 7,644 files, filter by neighbourhood and status, KPIs, monthly trend, location types, items stolen, priority, day×hour heatmap, 3D neighbourhood columns.

## Where to edit
- `src/data.js` — project titles, labels, summaries, and which 12 slabs appear on the stairs.
- `src/data/eholdup.js`, `src/data/mosspark.js`, `src/data/synth.js` — the numbers and points behind each page. Replace the synthesized Surrey/Green Timbers data with real exports when you find them.
- `src/data/resume.js` — resume text. Regenerate the PDF after editing (the generator script is in the chat where this was built; any reportlab script reading this file works).
- `src/components/MapView.jsx` — basemap style (OpenFreeMap, keyless), 3D buildings, terrain.
- `src/Background.jsx` — ShaderGradient colours/speed.

## Notes
- Map tiles come from OpenFreeMap and elevation from AWS terrain tiles — both keyless. Attribution is shown on the map.
- All four projects are labeled as coursework / training material on their pages.
